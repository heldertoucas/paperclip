# Paperclip Agent Guidelines

Welcome to `paperclip`. This project implements a system monitoring/clipboard companion.

## Technology Stack
- **Languages/Tools**: AutoHotkey v2 (AHK v2) for Windows automation and helper scripts.
- **Platform Parity**: Windows specific integrations reside in `win/`, macOS scripting in `mac/`.
- **Logs**: Memory monitoring logs and telemetry are stored in `perf_log.txt`.

## Agent Boundaries & Conventions
1. **Target Directory for Captures**: Any capture/screenshot outputs or dynamic artifacts generated by the scripts must be sent to the Obsidian vault inbox at:
   `00-inbox/pc/` (absolute path relative to the vault root `/Users/helder/Dev/obsidian-ht`).
2. **AutoHotkey Version**: Only write and maintain AutoHotkey version 2 syntax. Avoid version 1.x legacy syntax completely.
3. **No Polluted Roots**: Keep root directories clean; place new scripts in their respective platform directory (`win/` or `mac/`).
